# ForgeFlow — final sharing package

Read **SETUP.md** for installation and start/stop commands.

Includes 10 saved project folders, the latest draft-preview workflow, DeepSeek configuration, and platform tests. API keys, private accounts, databases, uploads, and historical runs are not included. Some projects are unfinished drafts.

Run setup to generate fresh local credentials, register your account, then import the source with scripts/import_projects.py. Use --local for no-Docker setup, startup, and import. No model key is required to inspect the saved apps.
