FIRST-TIME SETUP

From ZIP to localhost.

Extract the ZIP fully. Open the ForgeFlow folder. Choose one setup mode per extracted copy. Setup and previews do not call an AI model.

1

Install the basics

Install Python 3.12 or newer and Git. On Windows, enable Add Python to PATH. For the Docker setup, install and start Docker Desktop in Linux-container mode (Docker Engine + Compose on Linux). The first setup needs internet.

2

Choose your setup

Open a terminal inside the extracted ForgeFlow folder. Node.js is unnecessary; compiled CSS is included.

Windows · with Docker Recommended

Keep Docker Desktop running. Open PowerShell in the ForgeFlow folder and run:

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/setup.py
.\.venv\Scripts\python.exe scripts/manage.py start

The launcher builds the execution image and starts PostgreSQL automatically. The first run may take several minutes.

Windows · without Docker

This mode uses SQLite and runs generated code directly under your laptop account. Use it with trusted projects.

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/setup.py --local
.\.venv\Scripts\python.exe scripts/manage.py start --local
macOS / Linux · either mode
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python scripts/setup.py

Edit .env and set BROWSER_CHANNEL= (empty) to use installed Chromium. On Linux, install browser system dependencies with .venv/bin/python -m playwright install-deps chromium if needed.

# With Docker running:
.venv/bin/python scripts/manage.py start

# Without Docker: use setup.py --local above, then:
.venv/bin/python scripts/manage.py start --local
3

Open the website and create an account

Visit http://127.0.0.1:8791 on that laptop. Register your own account. You begin with an empty dashboard.

4

Import the included projects

Replace friend with the username you registered. Run this in a second terminal inside ForgeFlow, then refresh the dashboard:

.\.venv\Scripts\python.exe scripts/import_projects.py --username friend

For no-Docker mode, add --local. On macOS/Linux use .venv/bin/python. Imported projects are drafts: use Start draft preview to open them. Original accounts, run history, uploads, and databases are not transferred.

5

Add your own API key when you're ready to build

Open .env, put your DeepSeek key after LLM_API_KEY=, save, and restart the platform. GPT is disabled. You can inspect the included source and open previews before adding any key.

Submitting a request or pressing Resume uses API credits. The shared configuration has limits that pause work and preserve progress; they are not a guaranteed dollar cap.

Start & stop later

Windows: use Start ForgeFlow.cmd / Stop ForgeFlow.cmd, or their without Docker alternatives.

.\.venv\Scripts\python.exe scripts/manage.py stop
.\.venv\Scripts\python.exe scripts/manage.py start

Add --local to both commands in no-Docker mode. Closing a browser tab does not stop the server. Saved files remain after shutdown.

Present using Uvicorn

After first setup, stop the launcher. With Docker running, start its database and then the website manually:

docker compose up -d database
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8791

For an installation created with setup.py --local, skip the Docker command. Press Ctrl+C to stop Uvicorn. Use one worker. For macOS/Linux replace the Python path with .venv/bin/python.

Quick troubleshooting
  • Python not found: reopen the terminal after installation; try py -3 on Windows.
  • Docker unavailable: wait for Docker Desktop to finish starting, or use the no-Docker instructions in a fresh extraction.
  • Port in use: stop the other copy or add --port 8792 to both start and stop commands, then open localhost:8792.
  • No projects: register first, then import with the same username and mode.
  • Browser checks unavailable: Windows uses Microsoft Edge. Install Chromium and set BROWSER_CHANNEL= if Edge is unavailable.
  • API errors: check your own provider key, model access, balance, and provider limits. Opening an existing preview needs no model.
